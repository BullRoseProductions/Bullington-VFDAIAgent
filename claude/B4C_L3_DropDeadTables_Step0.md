### Notes for the gate
1. **S-1's premise is stale.** The review's HIGH "profiles appears to have RLS **disabled**" came from the stale `schema.sql`.
   Live, RLS is **ON** with no policy, which denies everything. The authenticated ALL grant is real but moot under RLS. So L-3
   is cleanup, not an exposure fix. Dropping still removes the latent risk: someone adding a permissive policy later.
2. **`_d2a_resync_backup` is D2a's undo store.** It holds the five default stations' pre-resync geo columns from Aug 27, two
   with coordinates and three NULL. Dropping it removes D2a §1's in-database rollback. **The committed backup keeps it**
   (`sql/l3_backup_rows.sql` restores it byte-for-byte; the dry run proves it). Two station coordinates therefore land in git
   history. They're fire-station locations, but noting it.
3. Postgres keeps no creation timestamp. "Created" above is the migration file plus the row timestamps for `_d2a`, and
   "predates the 2026-05-22 stats reset" for `profiles`.
