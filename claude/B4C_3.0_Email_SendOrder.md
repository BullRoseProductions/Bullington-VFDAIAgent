## Run sequence (the gate is enforced by the script)
Env needed: `RESEND_API_KEY`, `SUPABASE_SERVICE_ROLE_KEY` (prod).

1. `node scripts/send-3.0-announcement.mjs --dry` — confirm the recipient COUNT looks right (active + probationary, valid email, all real depts, minus owner/test/Demo). Expect a small number (the real member roster with emails).
2. `node scripts/send-3.0-announcement.mjs --test` — sends ONE to ashlea@b4thecall.com. **Ashlea checks it on a real phone:** links tap through to the right store pages, formatting holds, "Ask B4C" reads right, footer correct.
3. Only after Ashlea OKs the test: `node scripts/send-3.0-announcement.mjs --send --i-confirmed-the-test` — real run, one message per recipient, 600ms apart.
4. **Verify ACTUAL delivery** in Resend → Logs (delivered / bounced / complained). Report counts back. "Sent ok" from the script ≠ delivered.
